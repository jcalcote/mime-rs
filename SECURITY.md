# Security

Treat file contents and custom rule text as untrusted. Parsing is bounded, but a
successful classification or extraction does not establish that a file is safe.

Please report exploitable vulnerabilities privately using [GitHub's vulnerability
report form](https://github.com/jcalcote/mime-rs/security/advisories/new).
Do not include sensitive files or credentials. Include the affected version,
minimal public reproducer, observed impact and any resource limits involved.
The latest released version receives security fixes. No response-time guarantee
is made; this is a community project.
